# 🏆 Коллекция сертификатов

> ✨ Современный и стильный веб-сайт для демонстрации достижений и сертификатов

## 🎯 О проекте

Этот сайт представляет собой красивую галерею сертификатов с современным дизайном и плавными анимациями. Здесь собраны все мои достижения в области программирования и музыки, разделенные на две основные категории.

## 🌟 Особенности

- 🎨 **Современный дизайн** с градиентами и анимациями
- 📱 **Responsive дизайн** - отлично выглядит на всех устройствах  
- 🖼️ **Модальные окна** для просмотра сертификатов в полном размере
- 🏷️ **Разделение на категории** - программирование и музыка
- 📑 **Красивые заголовки секций** с анимированными разделителями
- ⚡ **Плавные анимации** появления карточек при прокрутке
- 🎭 **Hover эффекты** для интерактивности

## 🛠️ Технологии

- **HTML5** - семантическая разметка
- **CSS3** - современные технологии:
  - Grid Layout
  - Flexbox
  - Custom Properties (CSS Variables)
  - Анимации и переходы
  - Градиенты
- **JavaScript** - интерактивность:
  - Модальные окна
  - Intersection Observer API
  - Event handling
- **Google Fonts** - типографика Inter

## 🚀 Запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone <url-репозитория>
   cd Sertificates-main
   ```

2. **Откройте в браузере:**
   - Просто откройте файл `index.html` в любом современном браузере
   - Или используйте Live Server в VS Code для автообновления
